# Expense Tracker

A simple web application for managing expenses.

## GitHub

https://github.com/mohammedkhasawwneh/expense-tracker

## How to Run

1. Open PostgreSQL or pgAdmin.
2. Create a database called `expense_tracker`.
3. Open `backend/schema.sql` and run it in the database.
4. Go to the `backend` folder.
5. Copy `.env.example` and rename it to `.env`.
6. Add your PostgreSQL information inside `.env`.
7. Open the terminal in VS Code.
8. Run `npm install`.
9. Start the server with `node server.js`.
10. Make sure you see: `Server running at http://localhost:3000`.
11. Open the `frontend` folder.
12. Open `index.html` using Live Server.

## Features

1. Add an expense
2. Edit an expense
3. Delete an expense
4. Filter expenses by category
5. Show total expenses
6. Show number of expenses
7. Show highest expense
8. Dark mode
9. PostgreSQL database
